# 🎓 UNIGRAPH - GraphRAG Assistant

**UNIGRAPH** est un assistant académique intelligent utilisant la puissance des bases de données orientées graphes (**Neo4j**) et des modèles de langage avancés (**Llama 3 via Groq**). Ce projet a été conçu pour simplifier l'accès aux informations universitaires (cours, enseignants, salles).

## 🌟 Points Forts
- **Chatbot Contextuel** : Répond aux questions sur l'université en langage naturel.
- **Visualisation de Graphe** : Représentation interactive des relations entre entités (étudiants, cours, profs).
- **Administration Dynamique** : Interface dédiée pour mettre à jour la base de données en temps réel.

## 🛠️ Architecture Technique
- **Backend** : Flask (Python 3.10)
- **Database** : Neo4j (Cypher)
- **IA/LLM** : Llama-3.3-70b (Groq API)
- **Frontend** : Tailwind CSS, Vis.js
